## 采用来源与版本控制

### DeepSeek V4.1 Flash

- [官方 1017 更新](https://api-docs.deepseek.com/news/news261017/)、[1017 官方模型卡](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash-1017)：明确是当前网页/App/API 的版本；保留原 JSON id，并新增 current_version。
- 工程结果注明 Claude Code 与 Mini-SWE-V2 框架；不能把权重变化与框架变化当成同一个变量。
- [AA 未带日期版本比较](https://artificialanalysis.ai/models/comparisons/deepseek-v4-1-flash-vs-deepseek-v4-pro)、[Plotly 原始数据分析测试](https://plotly.com/blog/deepseek-v4-1-flash-data-analysis-benchmark/)：属于历史/未确认 1017 的测试，不伪装成新版实测。长文仍按 T3；数据分析主要采用新版图表任务，SQL/统计整体待重测。
- [ToneBench 1017 max](https://benchmark.towardsai.com/models/deepseek-v4-1-flash-1017-max-or.html)、[中文 1017 首发小测试](https://jishuzhan.net/article/2111755771935744002)：前者只测脚本，后者主要看约束执行，中文文学覆盖很有限。
- [9 月技术报告](https://arxiv.org/html/2609.19969v1) 中 LongBench V2 位于 Base 模型结果区，没有把它放进 instruct 当前评分。模型卡没有 MRCR 数字也如实记录。

### DeepSeek V4 Pro 0813

- [正式版官方卡](https://huggingface.co/deepseek-ai/DeepSeek-V4-Pro-0813)、[AA 明确 0813 的一手比较](https://artificialanalysis.ai/models/comparisons/deepseek-v4-pro-vs-glm-5-1-non-reasoning)：不借用 preview 的百万上下文成绩。
- [ToneBench 0813 max](https://benchmark.towardsai.com/models/deepseek-v4-pro-0813-max-or.html)、[Foreverse 中文正式版续写对决](https://foreverse.cn/zh/blog/deepseek-v4-pro-official-fiction-test)：同名 API 的旧 preview 与 0813 文风不同，旧排行榜不能迁移。后者是商业写作工具的单链、模型评委测试，不是普遍文学共识。
- 数据分析搜索找到 llmwise 与 OmicOS 的 V4 Pro 测试，但均不足以锁定 0813，所以不挪用成绩，只给 T3。

### Kimi K3

- [官方模型卡](https://huggingface.co/moonshotai/Kimi-K3)：保留 max、HLE 有/无工具、不同基准执行框架区别。
- [独立 AA 长文比较](https://artificialanalysis.ai/models/comparisons/deepseek-v4-1-flash-vs-kimi-k3)：新版 AA-LCR v1.1 不与官方发布时旧 AA-LCR 算模型提升。
- [英文原始作品和逐项评分](https://eqbench.com/results/creative-writing-v3/kimi-k3.html)、[英文用户原帖](https://www.reddit.com/r/SillyTavernAI/comments/1uz5ug0/kimi_k3_a_good_choice_for_rp/)、[中文同协议续写](https://foreverse.cn/zh/research/fiction-bench/kimi-k3)：兼顾对话/潜台词优势和设定追踪的个案失误；中文测试每书一条链，不外推所有小说。

### Hy3 正式版

- [正式模型卡](https://huggingface.co/tencent/Hy3)、[官方发布](https://www.tencent.com/tencent-hunyuan-officially-releases-hy3-advancing-agent-capabilities-and-deeper-product-integration/)、[AA 正式版比较](https://artificialanalysis.ai/models/comparisons/hy3-vs-mistral-small-4)。正式窗口为 256K，不是 1M。
- [官方附表原图](https://raw.githubusercontent.com/Tencent-Hunyuan/Hy3/main/assets/benchmark.png) 已查看，但不对无法可靠读出的单元格猜数字；正文可确认字段和 AA 直接结果优先。
- [SoloEnt 首章工作流](https://benchmark.soloent.ai/en/reports/writingflow_18models/) 为中文人类盲评，英文页面是同一测试译文，不算独立英文作品评测；写作置信度低。
- 专门数据分析搜到的大量财报案例实际上属于 preview，已排除；正式版仍 T3。

### MiMo-V2.5-Pro

- [官方卡](https://huggingface.co/XiaomiMiMo/MiMo-V2.5-Pro) 有明确 Base 区域与 post-training 长文结果；未把 Base GPQA 当 instruct GPQA。与多模态 V2.5 非 Pro、V2.6 Pro 区分。
- [独立 AA reasoning 比较](https://artificialanalysis.ai/models/comparisons/mimo-v2-5-pro-vs-gpt-5-2-medium)、[PinchBench 原始提交](https://pinchbench.com/submission/87439bfb-78ea-467d-bc6b-56a970c116f2)：新难题与基本办公自动化差距很大，不能只选高分。
- [英文 RP 用户原帖](https://www.reddit.com/r/SillyTavernAI/comments/1u30s6g/remember_when_i_said_i_like_mimo_i_was_wrong_i/)、[中文产品任务实测](https://www.woshipm.com/ai/6407526.html)、[SoloEnt 中文武侠首章](https://benchmark.soloent.ai/en/reports/writingflow_18models/)：样本和任务目标不同，综合保守评级。
- [OmicOS-BiomniBench 原始结果](https://github.com/omicverse/OmicOS-BiomniBench)：生物数据分析 rubric 测试、问题题目/运行失败剔除，以及 agent 源码尚未开放等限制均入 evidence；不是一般商业分析满量基准。
